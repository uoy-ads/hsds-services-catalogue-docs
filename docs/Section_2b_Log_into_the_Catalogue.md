# Log in to the Catalogue of Services

Once you have registered via UMA, you can now log in to create and edit your entries in the catalogue.

The login menu is found at the bottom right hand corner of the main catalogue page. Select “Service Provider Login”. 

![Service Provider login link](assets/service_provider_login.jpg){ width="850" }
<p align=center><i></i></p>

This login uses the same credentials (email address/password) as UMA.

If you do not yet have an account with the Catalogue of Services, please read the [How to Register via the User Management Application (UMA)](./Section_2a_Register_via_UMA.md) pages.
