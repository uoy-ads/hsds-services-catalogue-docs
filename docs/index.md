# Getting Started

The Heritage Science Data Service [**Catalogue of Services**](https://hsds.ac.uk/services-catalogue) allows users to find, and apply to use, heritage science research facilities from across the UK.

**What makes this catalogue unique?** This catalogue is an easy-to-use interface, allowing users to discover and access RICHeS facilities that are essential to their research. Resources within the catalogue can be filtered by Location, Organisation, Method/Techniques, and Asset Types, allowing users to quickly find, and apply to use, the most cutting edge facilities for their needs.

## How to Use This Guide

This guide will help you navigate the features of the catalogue, from basic searching and browsing to advanced data discovery.

**Getting around:** Navigate through the guide using the **menu on the left-hand side of the page**. The guide has been organised to build from basic concepts to more advanced features.

**Navigation features:**

* Use the search bar at the top of the page to find specific topics
* Your current page is highlighted in the menu
* On mobile devices, tap the menu icon (☰) in the top left hand corner to access the navigation pane

!!! note "**Pro tip**"

    Use the search function at the top of the page to quickly jump to any topic across the entire guide.
