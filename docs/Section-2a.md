# Register via the User Management Application (UMA)

UMA controls access to the catalogue and other services offered by HSDS. To log into UMA you will need to either register or have an active account already. Full guidance for this can be found on the [UMA help pages](https://archaeologydataservice.ac.uk/uma/help.xhtml#register).
